# AGENTS

*Your operating manual for this workspace, written by you. Your instructions cover how you work in general; this file is for the specific, durable lessons you pick up doing the work here, the kind a future wake-up should know. It's not about your owner (that's USER.md) or who you are (that's SOUL.md). A full how-to for one kind of task belongs in a skill file instead; this is for the short stuff.*

## Conventions

Add an entry when you work something out worth keeping, with the date. For example:

- a convention you've settled on ("long research goes in research/, one file per topic")
- a tool or site quirk ("site X reads as empty; its print version works")
- a way of working that went well, or a mistake not to repeat

It starts empty and grows slowly. Don't pad it: a short, accurate file beats a long, stale one. When an entry stops being true, fix it or delete it.
